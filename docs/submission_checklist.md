# Pre-defense Submission Checklist

**Deadline:** 24 October 2026 (as provided in university requirements).

## Single team submission form

- [ ] Official project title and supervisor details.
- [ ] Full legal names and GitLab/GitHub identities of every team member.
- [ ] Individual roles and contributions supported by commit history.
- [ ] Repository URL and YouTrack (or equivalent) URL.
- [ ] Single PDF of actual project-management board and task screenshots.
- [ ] Single PDF containing all 11 report components (convert assembled documentation at submission stage).

## Repository evidence

- [ ] Completed README with scope and development status.
- [ ] Proposal, literature review, existing system and technology comparisons.
- [ ] Functional/non-functional requirements and acceptance criteria.
- [ ] System context, use-case, and component diagrams with editable sources.
- [ ] Command examples, prototype notes, and verification plan.
- [ ] Supervisor feedback record and actual evidence of relevance.
- [ ] Traceable contributions from each participant and meaningful PR reviews.
- [ ] Requested submission tag when ready.

**Do not mark an artifact as completed until evidence is present.**
